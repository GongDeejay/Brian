# NeuroClassify · 认知神经科学分类与模式识别测验平台

Brian 认知神经科学实验平台的 `/neuro/` 子站。围绕**分类学习、规则发现与认知灵活性**
的一组测验，参考公开文献中的经典范式实现，并提供可调的认知负荷控制与结果分析。

线上地址：<https://brian.mplusm.site/neuro/>

## 任务范式

| 任务 | 测量的功能 | 主要指标 |
| --- | --- | --- |
| **WCST** 威斯康星卡片分类 | 概念形成、定势转换、持续性反应 | 完成分类数、持续性错误/非持续性错误、持续性错误率、概念水平反应、漏答 |
| **ID/ED** 注意定势转移 | 维度内/维度间转换（CANTAB 风格） | 各阶段错误数、EDS 错误、定势转移代价、达标/超限 |
| **WPT** 天气预测任务 | 概率分类、反馈学习（基底神经节环路） | 最优选择率、正确率、学习曲线、分块增益 |
| **原型畸变** | 类别表征与抽象化迁移 | 训练阶段正确率、迁移阶段原型优势效应 |
| **Gabor RB / II** | 外显规则学习 vs 信息整合 | 各条件正确率、达到学习标准的试次数 |

## 本地运行

```bash
npm install
npm run dev          # http://localhost:3001
```

**不需要任何环境变量或 API Key** —— 全部计算都在前端完成。

## 构建

```bash
npm ci
npm run build        # 产物在 dist/
npm run typecheck    # tsc --noEmit
```

> ⚠️ 本应用部署在子路径 `/neuro/` 下，`vite.config.ts` 里的 `base: '/neuro/'` 必须与
> 实际部署路径一致，否则资源会 404、页面白屏。改变部署路径时务必同步修改。

## 数据与隐私

测评记录保存在浏览器本地（内存 + `sessionStorage`），**不会上传到服务器**。
结果页提供 JSON / CSV 导出，请自行备份。

## 已知限制与使用边界

**请务必知悉**：本平台用于教学演示与科普体验，**不是经过验证的科研测量工具**，
其输出**不构成任何医学诊断或临床结论**。具体限制包括：

- **无标准化常模**：所有指标都是原始值与内部比较，不做「与人群比较」的百分位结论。
- **部分范式为简化实现**：例如 ID/ED 未实现完整的 9 阶段（缺少复合辨别逆转 CDR 阶段）；
  Gabor 任务没有视角（cycles-per-degree）标定与阶梯法阈值估计，因此只能做**同一设备内的相对比较**。
- **试次数偏少**：部分任务的试次数低于标准施测建议值，个体层面的指标稳定性有限，
  结果页会就精度不足给出提示。
- **浏览器计时精度**：刺激呈现依赖 `requestAnimationFrame` 与浏览器调度，不是毫秒级精确的
  实验控制软件；对时间精度要求高的研究请使用专用实验平台（如 PsychoPy / E-Prime）。
- **认知负荷控制**：部分调节项仅作用于部分范式，UI 中已逐项标注其适用范围。
