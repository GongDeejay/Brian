# 工作记忆训练与评估平台

BrIAN 认知神经科学实验平台的 `/wm/` 子站。集成了三个经典工作记忆范式，
在浏览器中完成施测、评分与可视化，并生成本地认知画像。

线上地址：<https://brian.mplusm.site/wm/>

## 任务范式

| 任务 | 测量的成分 | 核心指标 |
| --- | --- | --- |
| **N-back** | 工作记忆更新 | 命中/虚报、准确率、d′（信号检测论）、决策延迟 |
| **OSPAN** 复杂运算跨度 | 工作记忆存储容量 + 加工效率 | 绝对跨度分、部分得分、运算准确率、运算平均反应时 |
| **变化检测** | 视觉工作记忆容量 | Cowan's K = N ×(命中率 − 虚报率)，并按阵列大小分层报告 |

综合画像把三个任务的指标归一化为五个维度（更新、跨度、容量、速度、抑制），
并保留历史记录用于观察趋势。

## 本地运行

```bash
npm install
npm run dev          # http://localhost:3000
```

**不需要任何环境变量或 API Key** —— 全部计算都在前端完成。

## 构建

```bash
npm ci
npm run build        # 产物在 dist/
npm run typecheck    # tsc --noEmit
```

> ⚠️ 本应用部署在子路径 `/wm/` 下，`vite.config.ts` 里的 `base: '/wm/'` 必须与
> 实际部署路径一致，否则资源会 404、页面白屏。改变部署路径时务必同步修改。

## 数据与隐私

所有测评数据只写入浏览器 `localStorage`（键名 `wm_cognitive_platform_data_v1`），
**不会上传到任何服务器**。这也意味着：清除浏览器数据会丢失记录，且换设备不同步。
请使用结果页的导出功能自行备份。

## 已知限制

- 三个范式均为**简化实现**，用于教学与训练反馈，**不等同于标准化施测流程**
  （例如 OSPAN 每跨度仅一个 set，少于标准版的 3 个）。
- 尚未建立标准化常模，因此**不提供与人群比较的百分位或临床结论**。
- 变化检测每个阵列大小默认只有少量试次，K 值的分辨率有限，结果页会给出相应提示。
